开始部署 API 接入 场景方案 大模型网关

三步跑起来

生产部署一条命令（Docker Compose 自带 PostgreSQL/Redis）。本地源码开发请走 本地调试。

1

拉代码 + 子模块

git clone --recurse-submodules https://gitee.com/xiongrun/ai-lubricant.git
五个子模块随克隆一并拉取。

2

配 .env

cp .env.example .env，必改：POSTGRES_PASSWORD、AI_LUBRICANT_COMPAT_ENABLED=true、AI_LUBRICANT_BOOTSTRAP_ADMIN_EMAIL / _PASSWORD。

3

docker compose up

docker compose up -d --build，访问 http://127.0.0.1:3006，管理端 /manager，用户门户 /console。
