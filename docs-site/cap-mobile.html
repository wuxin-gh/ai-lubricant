手机客户端

面向发起、跟踪与复核开发任务的独立客户端，与 Web 门户同账号同后端，让你不在电脑前也能把任务推进下去。

问题没 App 时手机客户端
需求/bug 处理记在备忘录里等回电脑当场选项目/模型/节点发起任务
任务进度只能回电脑看任务列表、执行详情、Agent 输出、Token 统计随时看
文字输入慢手机打长描述很费劲按住麦克风流式语音转写，边说边出字
带素材截图/代码包没法带图片（≤2 MB × 3）与 zip（≤10 MB）附件预签名直传

功能清单

功能说明
任务与项目跟踪查看任务列表、状态、执行详情、Agent 输出与 Token 统计；查看项目概况与相关任务
新建任务选项目、模型与节点发起 AI 开发任务；模型来自授权 API Key，移动端不保存上游 Token；节点只显示 approved 且可用的 execution 节点
语音转写按住麦克风流式转写，支持中间结果和最终结果编辑
图片与 zip 附件相册/拍照图片（单张 ≤2 MB、最多 3 张）与 zip（单个 ≤10 MB），限制与 Web 一致
预签名直传先申请一次性上传地址，再 PUT 文件字节，提交任务时只带回 URL 与文件名；请求里不捎带文件二进制
下载升级市场管理页上传 APK，App 内下载、校验 sha256、调起系统安装；iOS 跳 App Store

边界

  • 移动端适合发起、跟踪、复核，不替代桌面编辑器、完整终端与高风险管理操作。
  • iOS 在新建任务/任务会话首次使用时弹 AI 数据处理同意确认，结果保本机；Android 不弹。
  • 技术栈：Expo SDK、React Native、Expo Router；支持 development / preview / production 三种 EAS 构建 profile。

怎么用

  1. 打开 App，登录页填写服务器域名（如 https://ai.example.com，不要填控制服务 8003）。
  2. 底部 Tab：任务 / 项目 / 我的。
  3. 点中央「+」新建任务：选项目、模型、节点，语音或文字描述目标。
  4. 提交后进任务详情跟踪执行。完整说明见 移动端手册。
