截图采集与发布规范

  • 截图必须来自当前运行版本的管理端页面，图注只描述画面中可确认的内容。
  • 桌面截图保留原始比例和清晰度，资源目录使用小写、短横线、无空格的语义化命名。
  • 必须完全隐藏 API Key、Token、Cookie、TOTP secret、节点安装命令、真实邮箱、IP、域名、仓库地址和客户内容。
  • 不修改业务状态或伪造数据；只允许必要裁切与脱敏遮挡。
  • 静态发布必须保留 assets/screenshots/ 的主题目录结构。
