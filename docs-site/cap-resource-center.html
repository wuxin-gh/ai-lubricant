资源中心

不用再翻 GitHub 各种 awesome 榜、复制 README、改 JSON、装依赖。平台已经把常用资源接好，你直接搜索、选择并用于 Agent、任务和编辑器。

问题以前使用资源中心
发现资源在 GitHub、各种 awesome 榜和社群里到处搜平台已接入 GitHub 著名资源榜单，常用资源集中展示、直接搜索
理解用途逐个打开仓库读 README资源带类型、来源、用途和说明，先看清再选择
安装配置复制配置、改 JSON、手动装依赖在资源选择器里勾选，随 Agent、任务或编辑器配置直接使用
跨场景复用每个项目重复找、重复装同一个资源可复用到多个 Agent、任务、编辑器和代码 Review

怎么用

  1. 在创建 Agent、任务、编辑器或代码 Review 时打开资源选择器。
  2. 按资源类型、名称或用途搜索。
  3. 查看资源说明，勾选当前场景需要的 Skill、MCP、提示词或插件。
  4. 保存后资源随当前配置生效；不需要手动编辑 JSON 或启动文件。
告别资源焦虑你不需要研究资源怎么进入平台，也不需要关心后台如何维护。资源中心只负责把已经接好的能力摆在你面前：找到、选中、使用。
