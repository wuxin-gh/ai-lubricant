幸运转盘 🎡

转一下，看看今天 Ai Lubricant 平台送你什么。纯前端实现，没有后端、没有接口、没有外部依赖——公平权重随机，缓动停下，中奖自动撒彩带。

今日剩余 5 次 已抽 0 次

点击中心 GO 或直接点转盘即可开始。每次抽完自动结算，中奖会弹窗并撒彩带。

奖品说明

转盘共 8 格，每格对应一个结果。并不是均匀概率——谢谢参与与小额 Token概率较高，终极大奖稀有。所有概率仅在本页前端按权重计算，与平台任何真实配额、计费无关。

奖品内容权重大致概率
关于“中奖”这里只是一个演示用转盘页面：所谓“奖品”不会真实发放，也不会写入任何账户或数据库。它只用来展示文档站也能承载交互式前端组件。真实用量、额度与 Token 请以平台控制台为准。

实现要点

  • 绘制：Canvas 2D 绘制金属外环、灯泡圈与 8 个扇形；扇形用径向渐变（中心浅、外缘深）增加立体感，配色取自文档站主题变量，浅/深色自适应。
  • 旋转：点击 GO 后，先按权重抽取目标扇形，再算出最终角度，用 requestAnimationFrame + easeOutCubic 缓动 4.5 秒停下，指针恒定在正上方。
  • 彩带：中奖时在覆盖层 Canvas 上撒粒子，物理衰减下落，2.5 秒后清理。
  • 次数：剩余次数存 localStorage，刷新不丢；抽完或手动重置可再来。
