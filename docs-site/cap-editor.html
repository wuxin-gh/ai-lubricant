连接编辑器

为每个项目提供可持续的工作环境：主流编码 CLI 接入、浏览器内编辑器、终端、文件管理，都在同一个项目上下文里。

问题自己搭的方案平台连接编辑器
编码工具接自有渠道改每个工具的配置/代码适配中转只改 base URL，平台按客户端模板补齐协议与字段
工作上下文片段粘贴进聊天，每次从空白开始项目/任务/编辑器/文件共享同一工作区
任务并行同一目录跑多个任务互相污染每个 session 独立 runtime 进程，目录隔离
文件与终端自己开 SSH/SFTP浏览器内直接用，走节点受控连接
提交身份Agent 用全局 Git 身份Git identity 按用户/项目关联

功能：接住主流编码 CLI

这些工具只改 base URL 指向你的渠道即可使用：

客户端平台构造的上游形态
claude-codeAnthropic Messages，保留 thinking 签名与 cache_control
codex-cli / codex-tuiOpenAI Responses，补齐 instructions / verbosity / reasoning.effort / prompt_cache_key
cursor（Cursor CLI / ACP）OpenAI Chat Completions；编辑器与 review 均可选用
gemini-cliGemini 形态，path 走模板占位符
cline · roo-code · opencode · workbuddyOpenAI Chat Completions

细节见 大模型网关的客户端模板；调用方视角的接入说明见 API 指南。

功能：更多编辑器与多环境选择

能力行为
更新的编辑器支持除 Claude Code / Codex / OpenCode 外，新增 Cursor CLI（ACP）与 Gemini CLI 作为编辑器和 review 执行端；编辑器清单随节点上报的 editor capabilities 动态发现，自定义编辑器 Agent 可引入新形态
分支模式（环境选择）创建编辑器时按 default / existing / auto 选择分支策略：用项目默认分支、指定既有分支、或自动开工作分支——同一项目可并存多个环境
编辑器多选一同一项目可创建多个不同 provider 的编辑器并行工作，互不串工作区
资源随编辑器下发MCP、技能、插件、项目提示词按编辑器单独配置，编辑即生效

功能：代码 review

对比项人工 review平台自动 review
触发时机记得点才看项目 webhook 事件（如 PR）自动触发
执行者人挤时间你选的编辑器（Claude Code / OpenCode / Gemini CLI / Cursor CLI）跑隔离 review skill
方法论各看各的框架化（如 OpenCodeReview Delegate）：确定性 diff + 规则脚手架，编辑器负责推理
并发与限流排队每项目并发上限可配；review 单独的 RPM/Token/并发限额，不打爆生产额度

review 任务类型（develop / design / review）与子类型（pr_review / diagnose_bug 等）同样可以手动创建；自动 review 的框架、执行编辑器、节点与资源在项目的 review 设置里一次配好。节点需上报对应编辑器 CLI 的能力标签才参与 review 调度。

功能：项目、任务与工作区

能力作用
项目统一承载仓库、任务、编辑器、提示词与成员边界
任务记录目标、执行状态、Agent 事件、结果和 Token 用量
编辑器项目的工作环境与会话入口，归属项目而非孤立 IDE
终端与文件浏览器内操作工作区或节点 PTY；文件浏览编辑无需 SCP/SFTP
Git identity提交身份与用户/项目关联

功能：多 task 隔离

机制行为
session = 独立 runtime 进程工作目录相互隔离，任务并行不打架
任务子 Key 收窄可用模型、编辑器、策略与速率限制派生成收窄的子 Key，任务级不越权
Git 走服务端反向代理节点 clone 用签名 proxy URL，真实 PAT 只在服务端内存；token 绑任务、只读、任务结束即失效
运行时预检缺 agent 运行时时 create ack 直接拒绝；终态无条件落库

功能：节点接入即为工作区

旧笔记本、办公室台式机装上节点程序即可作为执行环境——NAT 后面也行，不需要公网 IP 或开端口。普通任务不独占节点，容量由节点侧 max_sessions 控制。详见 节点能力详解。

功能：手机发起与跟踪

手机上选项目、模型与节点发起任务，查看执行轨迹与产物。移动端适合发起、跟踪、复核，不替代桌面编辑器。详见 手机客户端详解。

怎么用

  1. 从项目详情的「编辑器」Tab 创建编辑器，选工作节点与环境配置。
  2. 进入 /console/editor/:editorId，新建/恢复会话。
  3. 用完停止会话，释放节点容量。完整步骤见 开发者手册。
