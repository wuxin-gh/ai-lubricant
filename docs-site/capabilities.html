能力中心

除了一个可用的 LLM Token，Ai Lubricant 把整套系统集成一次做好。不再按一二级能力分类，而是按系统的集成列九大点：每个能力下方列出它的特色、解决的核心问题，并链入独立详解页把各项功能展开。

每张卡是一类系统集成：能力特色 + 解决的核心问题 + 进入详解。

⚖ LLM Server

特色：同协议直通不丢字段、客户端模板、多因子实时评分选路、九种冻结、双层限流重试、用量归一、四模式代理含节点出口。

解决的核心问题：中转只转不发——故障账号反复试、贵便宜账号一视同仁、丢字段让缓存和思考连续性失效。把字段保真、选路质量、韧性与可观测当核心能力。

⌘ Agent

特色：主/子 Agent 分工、终端 Agent、浏览器与网页内 Agent、邮箱 Agent、记忆增强；五种形态共享网关与权限。

解决的核心问题：Agent 只是"一个会聊天的循环"——跑在零散片段上、每次从空白开始、工具散落、上下文不持续。把同一内核放到不同载体，各管一类场景。

进入详解 →

▭ 编辑器

特色：接住 Claude Code / Codex / OpenCode 等主流 CLI、项目与任务上下文、三种执行环境（隔离 / 共用 / 系统，系统档接入现有的环境无需迁移远程连接）、浏览器内编辑器/终端/文件、Git identity。

解决的核心问题：Agent 在零散代码片段上工作、每次从空白开始、执行环境不持续。在明确项目和工作区中读写文件、运行命令、留下结果。

◇ 节点

特色：execution / management / passive_management 三角色、无需 SSH 主动连接、PTY/host exec/文件/HTTP 代理出口、TOTP AES-256-GCM 封存。

解决的核心问题：传统远程执行需开 SSH 端口、分发 SSH Key、维护轮换撤销；节点在 NAT 后不便中心拨入。让节点主动拨号、命令沿既有连接下发。

▣ 手机客户端

特色：任务与项目跟踪、新建任务与远程操控、语音转写、图片与 zip 附件、预签名直传、隐私边界、下载升级/EAS。

解决的核心问题：出门在外想到需求或 bug 只能记下来等回电脑。在手机上选项目/模型/节点发起任务并跟踪执行轨迹。

🌐 浏览器插件

特色：MV3 扩展把已登录的真实 Chrome 接入平台、12 个 CDP 工具、网页内 chat_* 帧对话、两类 token 隔离、按 client 绑定。

解决的核心问题：无头脚本每次新起临时实例跑完即丢——登录、验证码、已有会话很难处理。复用你正在用的真实浏览器和登录态。

进入详解 →

📲 Android/iOS 控制

特色：device-control MCP：配对码换 token、WebSocket v0 协议、15 个操控命令；无需 ADB 直控 Android（手机装控制 APK 即接）、无需 Mac 免签控制 iOS（服务端 go-ios 纯 Go 签名链 + WebDriverAgent，免费 Apple ID 也能自动签名续期）。

解决的核心问题：Agent 要操作手机 App 就得自己接 ADB / WDA、处理连接保活与凭据，iOS 还被 Mac + Xcode 手工签名绑死。把“读屏 + 下发操控命令”做成内置 MCP，配对一次即可被 Agent 调用。

✉ 邮箱

特色：邮件读取 MCP、按邮箱实例隔离只读、真实邮箱与别名标注来源、正文长度控制、附件默认元数据、token 绑实例。

解决的核心问题：Agent 要读邮件就得自己接 IMAP、维护登录态、处理附件与大正文。把"查当前邮件"做成按实例隔离的只读能力。

🛡 安全防护

特色：API Key 真正失效、子 Key 归并不越权、token 只存哈希、CDP/Mail/设备 token 绑实例、节点 TOTP 封存与审批、请求级观测。

解决的核心问题：Token 交给中转后，能不能真正收回、子 Key 会不会绕过总额度、工具凭据泄库怎么办、节点连上就能执行吗——全部答清。
